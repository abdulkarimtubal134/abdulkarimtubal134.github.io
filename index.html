About

$FORCEPUSH is a Solana meme coin for developers with questionable judgment. Pushy the hamster ships a free dev tool, Pushy Score: paste a public GitHub repo of AI agent skills, prompts or an MCP server and get a 0–100 risk score, findings with file and line, fix hints and a README badge. It runs in your browser: no account, no backend, nothing uploaded. You don't need the token to use it, and using it doesn't add value to the token.
