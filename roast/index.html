// How it works

3 to 5 GitHub API calls, some counting, and a big pile of hand-written jokes. No model, no server.

1. Read the log

Fetches the repo, its latest commits (up to 300, in pages of 100) and the contributor list. Results are cached in your browser for 15 minutes, so a refresh costs nothing.

2. Count the sins

Night and weekend commits, one-word messages, "fix", "oops" and revert counts, emoji, streaks, busiest hour and day, average message length and bus factor. GitHub reports commit times in UTC, so "night" means 00:00–04:59 UTC unless you shift the clock.

3. Pick the jokes

A deterministic template system chooses an archetype and a few lines based on the numbers. Same repo, same roast, so links are shareable. Hit "Reroll" for another take. Download the PNG or post it.

Just for fun. Not a code review. $FORCEPUSH is a meme coin, NFA.
