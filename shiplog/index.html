Hit GitHub's rate limit? Add an optional token

Anonymous GitHub API access is limited to 60 requests/hour per IP (and 10 searches/minute); a Ship Log uses 4 to 7. A token (no scopes needed) raises that to 5,000. It stays in this tab's memory, is sent only to api.github.com, and is never saved.

Automated summary, not an audit. Ship Log reads public GitHub metadata and sorts titles by prefix, label or keyword. It can be wrong or incomplete. It says nothing about code quality or safety. For a risk scan, try Pushy Score.

// How it works

4 to 7 GitHub API calls and some sorting. No model, no server.

1. Ask GitHub

Reads the repo, its releases, the PRs merged in your window (search API) and the latest 100 commits plus an exact commit count. Results are cached in your browser for 15 minutes, so a refresh costs nothing.

2. Sort by type

Titles starting with feat:, fix:, docs:, chore: (and friends) are grouped by that prefix. Without one, PR labels and a few plain keywords ("Fix…", "Add…", "Bump…") are used. Everything else lands in "other".

3. Share it

Copy the changelog as Markdown, download a PNG card, or post on X. Names link to GitHub profiles without @-mentions, so pasting it into an issue pings nobody.
