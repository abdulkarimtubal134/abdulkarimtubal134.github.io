A quick, rule-based risk scan for public GitHub repos of AI agent skills, MCP servers and prompt libraries. Paste a repo, get a 0–100 score, the findings with file and line, and a README badge. It runs in your browser: no account, no backend, nothing uploaded to us.

Hit GitHub's rate limit? Add an optional token

Anonymous GitHub API access is limited to 60 requests/hour per IP; each scan uses about 4. A token (no scopes needed) raises that to 5,000. It stays in this tab's memory, is sent only to api.github.com, and is never saved.

Automated scan, not an audit or guarantee. A high score means "none of our rules fired", not "safe". Read the blind spots and the code before you install anything.

// How it works

    
Four GitHub API calls, a handful of file downloads, and a pile of regexes. That's it, and that's the point: you can read all of it.

    

      
1. Pin a commit
Reads repo metadata and the latest commit, then lists every file at that exact SHA. Every file body is fetched from a SHA-pinned URL (jsDelivr, falling back to raw.githubusercontent), so the result describes one commit, not a moving target.

      
2. Pick the files that matter
Up to 40 files, 200 KB each, prioritising SKILL.md, AGENTS.md, CLAUDE.md, .cursorrules, MCP manifests, package.json, scripts and prompt files. Anything skipped is listed. Big folder? Paste a /tree/…/folder URL.

      
3. Run the ruleset
Secrets, dangerous exec, network exfil, prompt-injection strings, hidden Unicode, encoded blobs, remote-instruction fetches, permissions, docs and maintenance signals. Open, versioned, in rules.js.

      
4. Score, cap, badge
Four sub-scores roll into one number. Critical findings and skipped files cap the score so gaps can't hide behind a green number. Download a static SVG badge stamped with commit, date and ruleset.

    

    
Why a cap? Researchers have shown that skill scanners can be fooled with padding, bytecode, archives and prompt-injected judges. A scanner that quietly skips files and still says "100" is lying by omission, so Pushy lists what it didn't read and lowers the score accordingly.
